# 提醒小程序：需求与方案记录

## 已确认的使用方式

- 运行于这台 Windows 10 电脑，简体中文界面；优先提供免安装的单个 EXE。
- 首次打开默认 40 分钟。可设置 1 秒至 24 小时的单个一次性倒计时；提醒文字可留空，也可输入多行。
- 主界面的“设置倒计时”按钮打开独立时间选择窗口；时、分、秒可用鼠标滚轮、上下数字或键盘输入调整，确认后更新主界面显示。
- 主窗口显示剩余时间。可开始、暂停、继续；重置后回到原时长、停止并可编辑；结束会取消提醒，清空当前输入及本机保存的上次输入。
- 关闭主窗口后在系统托盘继续计时。托盘提供打开主窗口和直接退出。重复启动时打开已有窗口。
- 计时按实际经过时间计算。睡眠期间到点则唤醒后提醒；锁屏期间到点则解锁后显示。关机或重启后不恢复未完成计时。
- 到点后在当前屏幕中央显示置顶窗口，手动关闭。较长文字可滚动查看；文字为空时显示“时间到了”。默认播放一声短提示音，可静音。
- 正常提醒完成后保留上次输入与静音设置，不保存完整提醒历史，不开机自启。

## 技术与交付决策

选择 C# + .NET Framework 4.8 + Windows Forms。此电脑已内置所需运行环境和系统 C# 编译器，可在本机直接构建。Python + PySide6、Tauri 2 曾作为备选；Tauri 在此机还需 Rust 和 WebView2。

项目工作区：`D:\AI-WORK\all-codex\提醒小程序`。程序在工作区根目录；`源码/` 保留代码，`tests/` 保留检查，`design/` 保留界面草图。`D:\桌面\提醒小程序.lnk` 应指向工作区中的 EXE。Git 仓库以工作区为准。将来用户创建 GitHub 空仓库后再连接远端。

## GitHub 参考项目

开始制作前核对过以下项目，最终决定做精简专用程序：

- [Stefangansevles/RemindMe](https://github.com/Stefangansevles/RemindMe)：有快捷计时器和置顶提醒，提供安装文件；便携与完整计时控制未证实。
- [canikou/RemindMe](https://github.com/canikou/RemindMe)：有便携版、托盘后台和到期弹窗；完整暂停、重置等操作未从文档得到证实。
- [RTEventTimer](https://github.com/SethRobinson/RTEventTimer)：计时控制较齐，但关闭主窗口就退出，结束时修改原窗口内容而非新弹窗。

没有复制上述项目的代码。
