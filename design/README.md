# 界面草图

此目录保存界面草图与程序渲染预览：

- `current-main.png` / `current-picker.png`：当前“计时小程序”的主界面和时间设置窗口。

- `light-preview-view.html` / `light-preview.png`：最初的浅色布局。
- `tech-preview-view.html` / `tech-setup.png` / `tech-running.png` / `tech-alert.png`：深海蓝与青色强调的科技感方案，分别展示设置、计时和到点弹窗。
- `picker-dark.png`：更名之前“设置倒计时”窗口的渲染预览。

双击 `*-view.html` 可在浏览器中打开早期草图并切换状态。`light-preview.html` 和 `tech-preview.html` 是可编辑的原始预览；其中显示的旧名称属于历史草图。当前程序已采用科技感界面。

`light-preview-original-wrapped.html` 是首次会话预览目录中生成的原始页面归档；该目录中的旧副本已清理。
